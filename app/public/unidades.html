Unidades

Cada unidad se define contra la patrón de su magnitud: gramo para masa, mililitro para volumen, unidad para conteo. Con eso el sistema convierte entre cualquier par, y se niega a convertir entre magnitudes distintas.

La unidad de referencia es la que se usa para mostrar y cargar costos ("$1.200 por kg"). Hay una por magnitud.

Nueva unidad

Es la base de algún producto: no se le cambia magnitud ni equivalencia, porque las cantidades guardadas pasarían a significar otra cosa.
