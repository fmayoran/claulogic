GTIN interno Imprimir etiquetas de góndola

El SKU es el código propio del negocio. Cada producto recibe además un GTIN interno GS1 (prefijo 040, válido sólo dentro del negocio) para etiquetar lo que no trae código de fabricante.

Medida y presentaciones

Todo el stock, las recetas y los movimientos se llevan en esta unidad. Para masa conviene gramos y para volumen mililitros: las recetas se escriben así.

Cómo se compra: "caja x6" que contiene 6 kg. Se guarda convertido a la unidad base. El GTIN es el del fabricante para ese empaque (el sachet y la caja tienen códigos distintos): se puede escanear con la cámara o tipear. Para un empaque propio, "interno" genera uno.
